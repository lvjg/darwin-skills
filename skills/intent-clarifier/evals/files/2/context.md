# 保存与搜索的设计依据

## 已确认范围

这份决定供研发实施保存与搜索交接时使用，不是对外公告。保存成功表示数据库事务已经提交；搜索索引异步更新，没有已承诺的可见时限。索引更新失败必须对管理员可见，管理员可以对单条记录手动重试。本次不承诺自动恢复或批量补偿。

技术表达与文档组织交给 Agent 决定。允许直接完成指定设计决定文件，不需要再次审批文案；不授权代码修改或上线。

## 当前事实

保存接口在事务提交后返回成功，索引任务在后台消费。测试环境的有限样本通常两秒内完成索引更新，没有生产延迟分布或负载验证。失败记录包含记录 ID、可展示的原因和单条重试入口。

## 尚未建立的依据

没有生产索引时限承诺，是否增加此类承诺不属于本次决定。不能以两秒样本推导生产 SLA。
