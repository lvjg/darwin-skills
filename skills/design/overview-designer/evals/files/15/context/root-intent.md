# 目标与决策边界

客户付款前必须看到每个商品行是否能寄送到所选地址，以及不可寄送的原因。所有正常调用 p95 的验收上限是 250 ms；依赖不可用或数据无效时显示资格暂不可确定，不能假报 eligible 或确定性拒绝。

产品负责人已确定：在满足结果、250 ms 和正确失败语义后，本次六个月决策周期优先降低两团队合计的增量工程投入。进一步降低已经达标的延迟不单独优先。路线选择已委托，但不能改变目标、标准、事实归属或决定优先级。

只有 design/system-design.md 可修改。不实现代码；文档要说明可检验的设计、取舍和适用条件，不将估计或原型证据写成生产证明。

Logistics 给出的当前业务计划是在该六个月周期内更新规则 1 次；本题所有比较使用这个计划数量，实际频率变化时应重新核对选择。
