# Notification preference authority intent

A user's accepted notification preference must govern every subsequent campaign or support notification within one minute. The user and privacy operator must be able to recover one authoritative current decision rather than reconcile several competing copies.

The privacy owner has assigned semantic authority and mutation ownership to Preference Service. Route selection and the responsibility changes required to satisfy the result are delegated. Temporary transition is allowed for named active consumers, but old independent writers must retire; permanent dual write and indefinite reconciliation are not acceptable target states.
