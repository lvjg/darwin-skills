# Access-request assistant intent

An internal employee should be able to ask an assistant to request temporary privileged access.

- A successful submission means only that an access request exists.
- The assistant must distinguish submitted, pending, approved, and rejected states.
- The employee may use the privileged system only after authoritative approval.
- If approval state cannot be obtained, the assistant must expose that uncertainty.
- The user asks whether the proposed Agent/Harness design is ready to implement.
