# 当前数据与运行环境

全部指标为合成评测基准，允许据此估算设计，不能声称已验证生产 SLA。

- Gateway 请求上限 30 秒，支持流式响应但不支持超过 30 秒长连接；单进程内存 256 MiB，需要同时服务普通请求。客户端断开会取消该 HTTP 处理，但不能撤销已经创建的数据库记录。
- 自有 Analysis Service 已有租户权限检查及结果查询 API。新增导出记录、接口和 worker 属于允许范围；现有 PostgreSQL 可做本地事务，现有至少一次工作队列支持租户并发限制和延后重试。
- 查询源为独立只读分析集群，不是 PostgreSQL 业务库。POST /snapshots 接受租户、列和过滤器并返回 snapshot_id、created_at、row_count、estimated_bytes、initial_cursor；调用时间小于 2 秒，权限检查由 Analysis Service 在创建前执行。快照在创建后固定可读 60 分钟，无续租，若过期必须重新创建新快照。返回的估计大小可有 50% 误差，row_count 精确。除首个游标外只接受上一页返回的 next_cursor，不支持 offset。
- GET /snapshots/{id}/pages?cursor=... 每页最多 8 MiB 的已解码行值；某行超过通常批次目标时仍完整返回，单行最大 4 MiB。分页同快照固定稳定顺序；返回末页 next_cursor=null，失败时可用同游标重读同页。平均延迟小于 100 ms，足够并发下集群给所有导出共 40 MB/s；单个导出不超过 30 MB/s。集群另有在线查询负载，不允许提高导出总配额。
- 独立后台 worker 每个 512 MiB、2 vCPU；最多允许同时 2 个，每个 CSV 转换合成吞吐约 22 MB/s，不得占用 Gateway 进程作无界后台执行。任务进程可能被终止，队列可能重投，重试不能把半个文件标作成功。
- 已有对象存储兼容 S3 multipart upload，支持流式上传分片、失败中止、完整提交后才暴露最终对象；单对象上限 5 TiB。可以服务大文件下载，不占 Gateway 传输。未完成 multipart 需 1 天生命周期自动清理，也可主动中止；完整对象可按 24 小时规则清理。桶不公开，服务端可按对象签发最长 60 秒下载 URL。对象存储账号不能给浏览器。
- 现有页面有查询列表、下载按钮、全局错误提示，支持定时重新读取任务列表。没有通用导出平台或邮件服务。允许统一处理所有规模，也允许区分路径，但应让用户结果与容量限制成立。
