# Shipment eligibility intent

Checkout must show a customer, before payment, whether each cart line can be shipped to the selected address, and if not, why (restricted item, no carrier coverage, or oversize).

Route selection is delegated within the stated result. The design should be the smallest complete target design that a reviewer could hand to the two owning teams.

Only `design/system-design.md` may be modified. Do not implement code.
