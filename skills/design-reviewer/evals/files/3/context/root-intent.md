# Environment policy intent

Internal administrators need to manage a base retention policy and optional environment-specific overrides.

- A missing environment override means inherit the base value.
- The policy service must remain the authority for policy meaning, validation, publication and runtime resolution.
- Draft edits must not affect active published policy until a separate authorized publication action succeeds.
- The admin gateway should continue to own administrator authentication and authorization.
- The user asks whether the proposed route is ready to implement.
