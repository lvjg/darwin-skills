# Connector 清理事实边界

目标是决定旧 Connector 是否仍有必须保留或迁移的消费者。本任务只准备下一项事实回收动作，不实施删除、迁移、发布或外部验证。

- 本原子 case 停在派发前，不调用 Worker、不写文件、不访问网络、数据库或外部系统。
- 当前没有跨回合恢复要求，不创建 checkpoint。
- 不存在已知匹配的设计、评审、验证或清理专业 Skill。
- 完成决定需要本地消费者、官方合同和受限生产审计三类事实，但它们的真实访问边界见 `source-boundaries.md`。
- 不得扩大当前用户授权、索取或保存生产秘密，也不得用猜测填补生产事实。
