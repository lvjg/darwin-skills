# Checkpoint 文件合同

本合同定义 Supervisor 私有控制快照的载体、格式、状态语义及恢复退出规则。启用条件、阻塞与完成判定以 `SKILL.md` 为准；文件只保存当前控制快照，不承担领域产物、过程日志或 Worker 交接职责，也不交由 Worker 读写。

## 载体与原位更新格式

优先沿用用户或任务已指定的有效 checkpoint 文件；未指定时使用当前项目根下的 `.supervisor/<task-id>.md`（Task id 沿用已有稳定标识或任务短名加抗冲突后缀；不另建平行文件，无合法可写位置时不建立并告知用户）。

沿用已有载体的可用格式；新建文件使用如下紧凑 Markdown 结构（删除不适用项，每次写入**原位替换**当前值并移除已无控制用途的项）：

```markdown
# <task reference> — <Active | Waiting | Blocked | Complete>

- Result: <根结果与验收边界>
- Constraints: <当前授权、禁止效果、必须保持的用户决定；更正时原位替换，不存决策过程或失效选择>
- Basis: <直接权威、设计与当前候选版本引用；对象或权威替换时移除旧绑定，不累积历轮 SHA 或候选列表>
- Open: <按未闭合的用户结果或独立阻塞条件表达当前差距、依据与责任，明确当前选中项；闭合或失效即移出，不留已完成列表；可从权威产物重取的子项仅引用>
- Action: <当前责任、输入引用、允许作用、预期证据、停止条件；接纳返回后替换，不保留已结束的派发、查询或等待历史>
- Effects: <活动资源及管理/清理 Owner；效果未知操作的原引用与恢复条件（操作名称不能代替查询所需的地址或定位信息）；终态确定且清理闭合后移除>
- Evidence: <仍支配当前判断或完成的结论、适用对象与直接权威证据引用；已闭合义务保留仍适用的报告引用即可，被覆盖、前提失效或可从权威产物重建的正文移除>
```

每条信息须服务下一动作、恢复或完成判断，同一事实只表达一次，信息量不随执行轮数增长。不追加返回摘要、旧快照、完成历史或 `LATEST`／`CURRENT` 段落；不含秘密、完整提示词、能力目录、Worker 对话或未证明的未来阶段。Worker 引用仅在仍用于续派、取回结果或查询效果时保留（带任务树或会话归属），并行时保留每项未终结或效果未知的责任。

## 状态语义

状态描述整个任务，待派责任与原操作效果分别记录：

- `Waiting`：存在仍在执行、权威终态或实际效果未知的已接受动作，且可按既定条件安全等待或查询。记录原操作、反馈来源、预期证据和停止条件；同时仍可推进其他独立责任。
- `Active`：尚有可推进的责任，但没有符合 `Waiting` 条件的原操作。其他受阻原操作的未知效果仍须保留，状态变化本身不构成重试依据。
- `Blocked`：符合主文阻塞条件（含等待 Owner 解除权限、能力或决策阻塞而无约定回调或安全查询条件）。记录实际 Owner、最小解除条件，并保留未知效果、原操作引用和恢复入口。
- `Complete`：符合主文完成条件，文件不可继续恢复。

局部返回、超时或下一查询尚未派发，都不能覆盖原操作的未知效果。`Needs Authority`、`Needs Input` 是阻塞原因而非新状态；不得用 `Deferred` 隐藏未闭合义务。

## 写入、恢复与退出

只在恢复相关信息或状态变化时写入（重复等待、轮询、普通进度或内部路由无控制事实变化时不写入）：

1. 接纳改变决定的事实、义务、授权或路线后，在执行依赖动作前更新；
2. 派发前保存当前依据、责任、边界、预期证据和停止条件（不提前标为已派发）；接收、返回、超时或失败后按任务实际活动与效果更新。**准备查询不会清除原操作，也不会因查询尚未派发把原有 `Waiting` 改成 `Active`**；
3. 交还控制、进入 `Blocked` 或完成退出时更新。

**恢复与退出**：
- 若动作可能已产生效果，但对应 `Waiting` 尚未落盘就发生中断，恢复时将效果视为未知，不得依据旧 `Active` 直接重试。恢复后先读取 checkpoint，再刷新可能变化的权威来源；载体缺失或被他人改动时按当前状态重写并告知用户。
- 首次接管含多份新旧状态或截断输出的遗留文件时，先分段补齐并核对当前目标、授权、全部开放义务和活动/未知效果，再替换为单一当前快照；压缩或环境切换后，先核对必要 Worker 引用的任务树归属、责任与上下文（相同路径不证明是原 Worker）。
- 完成且确认无活动或效果未知动作后：用户或任务指定的既有载体更新为不可继续恢复的 `Complete`；Supervisor 新建的临时 checkpoint 在最终回复前删除（`.supervisor/` 因此变空时一并清理）。最终只报告领域结果和证据，不把 checkpoint 当成交付物。
